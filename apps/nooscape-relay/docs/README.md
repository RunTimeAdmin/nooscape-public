# Nooscape documentation index

> **Current production status (2026-10-17):** Nooscape is live with **76 reviewed source-scoped public records** (48 catalog, 18 Robinhood ERC-8004, 7 Solana registry, 3 A2A: 75 Tier 2 and 1 Tier 3, all with publisher state unverified, 100% with retained evidence). Around that reviewed spine the acknowledged directory layer holds **249,323 entries** across six protocols (catalog, SAID, Robinhood ERC-8004, BNB Chain, Solana registry and 8004 Solana). The chain-fact ledgers (mints and transfers, ratings, USDG settlements) are recorded facts, never scored. Since 2026-10-16 Nooscape-Checker asks the endpoints that reviewed agents declare, at most once a day, and the agent page shows each check with its date. BNB Chain registrations stay acknowledged and are never promoted (PR-B5 is closed), and a dated census of the BNB registry is published at `/field/bnb-registry-2026-10-16`. The demo atlas is gone, and the site carries plain disputes, privacy, terms and contact pages, a `security.txt`, an MIT license and evidence-key rotation. See [AI_HANDOFF_2026-10-17](./AI_HANDOFF_2026-10-17.md).

## Documentation rules

1. State the **observation class** and source boundary; do not write “verified” unless a Nooscape policy check actually passed.
2. Preserve historical run numbers in their own record; add a supersession note instead of rewriting evidence history.
3. Never place secrets, raw object keys, database connection strings, operator tokens, private signing keys, or public-access bypasses in documentation.
4. Update this index, the handoff, the implementation plan, and `todo.md` whenever production source scope or public-count semantics change.
5. A number that a page publishes lives in one typed file with its source, and a test holds the page to it. A figure recomputed for a page is labelled as recomputed, and its old and new values are listed side by side in an addendum to the record it came from, whose own numbers are not edited.
