## Guardrails

- No arbitrary public fetch URLs: a source needs an approved hostname boundary, and the informational checks and the name reads ask only addresses that an approved source's reviewed records or registrations name, through the shared safe fetch, within the limits in the 2026-10-15 decision record.
- Fetches are bounded, parse only metadata, and never execute discovered agent tools.
- Raw payloads use content-addressed immutable object references; the relational database stores provenance, hashes, and normalized projections.
- A record does not become publicly trusted solely because it was discovered.
